# For Loops: Print Squares

## Task

The provided code stub reads an integer `n`.

For every integer `i` from `0` up to, but not including, `n`, print the square of `i`.

---

## Python Solution

```python
n = int(input())

for i in range(0, n):

    print(i ** 2)
```

---

## Step-by-Step

### 1. Read the input

```python
n = int(input())
```

`input()` reads the value as a string.

`int()` converts it to an integer.

The value is stored in `n`.

---

### 2. Start the `for` loop

```python
for i in range(0, n):
```

This loops through the values generated by:

```python
range(0, n)
```

The important rule is:

> The start value is included, but the end value is excluded.

So if:

```text
n = 5
```

then:

```python
range(0, 5)
```

produces:

```text
0, 1, 2, 3, 4
```

---

### 3. Square each value

```python
print(i ** 2)
```

The `**` operator means **exponentiation**.

So:

```text
0 ** 2 = 0
1 ** 2 = 1
2 ** 2 = 4
3 ** 2 = 9
4 ** 2 = 16
```

Each result is printed on a separate line.

---

### Input

```text
5
```

### Loop values

```text
i = 0

i = 3
i = 4
```

### Output


# Understanding `range()`

The general form is:

```python
range(start, stop)
```

It generates values from `start` up to, but **not including**, `stop`.

For this problem:

```python
range(0, n)
```

means:

```text
start at 0
→ keep increasing by 1
→ stop before n
```

### Example

```python
range(0, 3)
```

produces:

```text
0, 1, 2
```

It does **not** include `3`.

---

# Why Does the Loop Stop at `n - 1`?

Suppose:

```text
n = 3
```

Then:

```python
range(0, 3)
```

gives:

```text
0, 1, 2
```

The value `3` is excluded.

Therefore the program prints:

```text
0
1
4
```

because:

```text
0² = 0
1² = 1
2² = 4
```

---

# Equivalent `while` Loop

The same logic can be written using a `while` loop:

```python
n = int(input())

i = 0

while i < n:
    print(i ** 2)
    i += 1
```

The `for` loop is more concise when iterating through a known sequence of values.

# Common Mistakes

## 1. Using `range(n + 1)`

Incorrect:

```python
for i in range(0, n + 1):
```

That would also process `i = n`.

The problem requires values where:

```text
0 ≤ i < n
```

So:

```python
range(0, n)
```

is correct.

---

## 2. Using multiplication instead of exponentiation incorrectly

Correct:

```python
i ** 2
```

This means:

```text
i × i
```

For example:

```text
4 ** 2 = 16
```

---

## 3. Forgetting indentation

The statement inside the loop must be indented:

```python
for i in range(0, n):
    print(i ** 2)
```

Without indentation, Python will not treat `print()` as part of the loop.

# Key Takeaways

### `for`

Used to repeat an operation for each value in a sequence.

### `range(0, n)`

Generates:

```text
0, 1, 2, ..., n - 1
```

### `** 2`

Squares a number:

```python
i ** 2
```

means:

```text
i × i
```

### Overall flow

```text
Read n
↓
Generate 0 to n - 1
↓
Take each i
↓
Calculate i²
↓
Print
↓
Repeat
```
